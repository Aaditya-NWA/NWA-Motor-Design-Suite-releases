# NWA Motor Design Suite: releases

Installers for NWA Motor Design Suite, by Nautical Wings Aerospace, and the update feed the app reads
(`latest.json` of the newest release). No source code is kept here.

To install, download the newest `NWA-Motor-Design-Suite_<version>_x64-setup.exe` from Releases and run it. Windows may
warn about an unknown publisher the first time: More info -> Run anyway. Later versions arrive through the app:
Settings -> Check for updates.
